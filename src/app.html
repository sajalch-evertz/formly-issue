ngx-formly 7.1.0: a schema default is applied only once

  • A schema default is written into the model only when its field appears on screen.
  • Each write to the form hands Formly a new object, and only the first write makes the branch appear.
  • So every later write leaves the branch fields blank. Name, outside the oneOf, survives.

Stock field types, Bootstrap as a stylesheet only. Full write-up in the README.

Issue 1: a default is applied only when its field becomes visible

  • Card 1 holds the branch defaults. Card 2, the same object after the second write, does not.
  • Switch the branch and back and they reappear; press Discard and they go again, because a discard is another write.
  • URL has its own "hide": "!formState.isAdmin" with the flag true, so it is visible throughout and still loses its default. Timeout (ms) has none, only the branch's.

Issue 2: switching branch leaves the form pristine

  • Switch the selector: the model changes, form.dirty stays false, Discard stays disabled.
  • The selector Formly builds has no key, so its control is never attached to the form.
